

# DevScale — Enterprise Task Management SaaS

DevScale is a **modern, responsive SaaS landing page** designed for enterprise-grade task and project management platforms.
It focuses on **clean typography**, **bento-style layouts**, and **scalable design tokens**, inspired by real-world SaaS products.

---

## Features

  **Modern SaaS UI**
  **Bento Grid Layout** for feature presentation
  **Design Tokens (CSS Variables)** for easy theming
  **Fully Responsive** (mobile-first adjustments)
  **Enterprise-ready visual language**
  **Clean & Scalable Code Structure**

---

## Tech Stack

* **HTML5** – Semantic, accessible structure
* **CSS3** – Modern layouts (Grid, Flexbox)
* **Google Fonts (Inter)** – Clean enterprise typography
* **No JavaScript** – Lightweight & fast

---
